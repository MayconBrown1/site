Política de Privacidade

Resposta Rápida WhatsApp e Facebook – Maycon Brown

Última atualização: 05 de agosto de 2026

Esta Política de Privacidade descreve como a extensão Resposta Rápida WhatsApp e Facebook – Maycon Brown trata as informações dos usuários durante sua utilização.

1. Finalidade da extensão

A extensão foi desenvolvida para facilitar o atendimento ao cliente, permitindo o envio de mensagens rápidas e a organização de respostas no WhatsApp Web e Facebook Messenger.

2. Coleta de dados

Esta extensão NÃO coleta dados pessoais dos usuários.

A extensão não coleta, registra, transmite, vende ou compartilha:

  • Nome;
  • E-mail;
  • Número de telefone;
  • Mensagens pessoais;
  • Dados bancários;
  • Senhas;
  • Localização;
  • Histórico de navegação;
  • Conteúdo das páginas visitadas além do necessário para o funcionamento da extensão.

3. Armazenamento local

As configurações da extensão, incluindo mensagens rápidas, preferências do usuário e demais ajustes, podem ser armazenadas localmente utilizando a API chrome.storage.

Esses dados permanecem armazenados exclusivamente no navegador do próprio usuário e não são enviados para servidores da Maycon Brown.

4. Permissões utilizadas

A extensão utiliza apenas as permissões necessárias para oferecer suas funcionalidades.

  • Storage (armazenamento local de configurações);
  • Scripting (execução dos scripts da própria extensão);
  • Acesso às páginas do WhatsApp Web e Facebook Messenger exclusivamente para disponibilizar as funcionalidades da extensão.

5. Compartilhamento de informações

Nenhuma informação é vendida, compartilhada ou transferida para terceiros.

6. Código remoto

A extensão não executa código JavaScript remoto para alterar seu comportamento e não utiliza mecanismos destinados à execução dinâmica de código hospedado em servidores externos.

7. Segurança

A extensão foi desenvolvida seguindo as boas práticas recomendadas pela Chrome Web Store, utilizando apenas as permissões necessárias para seu funcionamento.

8. Alterações nesta Política

Esta Política poderá ser atualizada sempre que houver alterações na extensão ou em requisitos legais.
