Comandos de Reparo do Windows

Execute o CMD ou Terminal como administrador e utilize os comandos abaixo.

Para uma verificação completa, execute os comandos na ordem apresentada.

1º PASSO

Verificação Rápida da Imagem do Windows

DISM /Online /Cleanup-Image /CheckHealth

O que esse comando faz?
Faz uma verificação rápida para saber se o Windows já detectou algum problema ou corrupção na imagem do sistema.

Ele não realiza uma análise profunda e não faz nenhum reparo. É usado principalmente como uma verificação inicial.

2º PASSO

Verificação Completa da Imagem do Windows

DISM /Online /Cleanup-Image /ScanHealth

O que esse comando faz?
Faz uma análise mais completa da imagem do Windows procurando arquivos e componentes corrompidos.

Essa verificação pode demorar alguns minutos. O comando apenas identifica os problemas e não realiza o reparo.

3º PASSO

Reparar a Imagem do Windows

DISM /Online /Cleanup-Image /RestoreHealth

O que esse comando faz?
Verifica a imagem do Windows e tenta reparar automaticamente os componentes corrompidos encontrados.

Quando necessário, o Windows pode utilizar o Windows Update para obter arquivos íntegros e substituir componentes danificados.

Aguarde até chegar a 100% antes de fechar a janela.

4º PASSO

Verificar e Reparar Arquivos do Sistema

sfc /scannow

O que esse comando faz?
Verifica os arquivos protegidos do Windows e procura arquivos ausentes, modificados ou corrompidos.

Caso encontre problemas, o próprio Windows tenta substituir os arquivos danificados por cópias corretas.

É recomendado executar este comando depois do DISM /RestoreHealth.
