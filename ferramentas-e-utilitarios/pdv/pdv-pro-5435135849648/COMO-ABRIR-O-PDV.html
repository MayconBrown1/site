Como abrir o PDV Pro

Guia rápido para executar o sistema pelo PowerShell.

Abrir no seu computador

1

Abra no Explorador de Arquivos a pasta pdv - pro.

2

Clique na barra de endereço da pasta, apague o endereço, digite powershell e pressione Enter.

3

Na janela azul do PowerShell, cole este comando e pressione Enter:

powershell -ExecutionPolicy Bypass -File .\iniciar-pdv.ps1
4

O navegador abrirá automaticamente. Se não abrir, acesse http://localhost:8000.

5

Para desligar o servidor, volte ao PowerShell e pressione Ctrl+C.

Importante

O endereço localhost funciona somente neste computador enquanto a janela do PowerShell estiver aberta. Ele não publica o sistema na internet.

Se aparecer uma mensagem dizendo que a porta 8000 está ocupada, use:

powershell -ExecutionPolicy Bypass -File .\iniciar-pdv.ps1 -Porta 8080

Nesse caso, acesse http://localhost:8080.

Publicar na internet de verdade

Este projeto já está configurado para o Firebase. Depois de instalar e conectar o Firebase CLI, o comando de publicação da parte visual é:

firebase deploy --only hosting

O endereço configurado no projeto é https://pdv-brown.web.app/login.html. Para a configuração completa, consulte o arquivo README.md desta mesma pasta.
