🛠️ Correção Definitiva: Erro Sentinel LDK 0x7101 no Wilcom

Guia completo para remover automaticamente o erro de licença do Wilcom Embroidery Studio

📋 O que é o erro 0x7101?

O Sentinel LDK Protection System é o sistema de licenciamento da Thales (Gemalto). O erro 0x7101 indica falha na verificação da licença do Wilcom.

Os arquivos "Remove LDK" apagam a chave de registro HKEY_CURRENT_USER\Software\Gemalto, mas o sistema a recria periodicamente (por isso volta a dar erro).

📁 Arquivo BAT Silencioso

Crie um arquivo chamado Remove_LDK_Silencioso.bat com este conteúdo:

@echo off
>nul 2>&1 (
  reg delete "HKEY_CURRENT_USER\Software\Gemalto" /f
)
exit

🔧 Como funciona:

  • @echo off — desativa exibição dos comandos
  • >nul 2>&1 — oculta TODA a saída (silencioso)
  • Apaga a chave Gemalto do registro sem mostrar nada na tela

💾 Salve em: C:\Tools\Remove_LDK_Silencioso.bat

⚙️ Configurar Execução Automática Diária

Passo 1: Abrir o Agendador de Tarefas

Pressione Win + R, digite taskschd.msc e pressione Enter

Passo 2: Criar nova tarefa

No painel direito, clique em "Criar Tarefa..."

📌 Aba "Geral"
  • Nome: Remove LDK Wilcom
  • ☑️ "Executar estando o usuário conectado ou não"
  • ☑️ "Oculta" (não aparece na tela)
  • ☑️ "Executar com privilégios mais altos"
📌 Aba "Disparadores" → Clique em "Novo..."
  • Opção A: "Ao fazer logon" — executa toda vez que ligar o PC
  • Opção B: "Diariamente" — escolha o horário (ex: 09:00)
📌 Aba "Ações" → Clique em "Novo..."
  • Ação: Iniciar um programa
  • Programa/script: C:\Tools\Remove_LDK_Silencioso.bat
📌 Aba "Configurações"
  • ☑️ "Executar a tarefa assim que possível se uma programação for perdida"
  • ☑️ "Se a tarefa falhar, reiniciar a cada: 1 minuto" (3 tentativas)

✅ Clique em OK e digite sua senha do Windows quando solicitado.

🔄 Alternativa: Script VBS (100% Invisível)

Se ainda aparecer alguma janela, use este script VBS que executa o BAT de forma completamente oculta:

Set WshShell = CreateObject("WScript.Shell")
WshShell.Run chr(34) & "C:\Tools\Remove_LDK_Silencioso.bat" & Chr(34), 0
Set WshShell = Nothing

💾 Salve como: Executar_Silencioso.vbs

🔧 No Agendador de Tarefas, aponte para o arquivo .vbs em vez do .bat

📊 Resumo dos Arquivos

Arquivo Função
Remove_LDK_Silencioso.bat Apaga o registro silenciosamente
Executar_Silencioso.vbs (Opcional) Executa o BAT 100% invisível

🎯 Pronto! Agora o erro não vai mais te incomodar — o sistema vai "limpar" automaticamente todo dia ou toda vez que ligar o computador.
